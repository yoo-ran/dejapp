# 🏡 DEJ App — Real Estate Mobile Platform

**DEJ App** is a mobile-first real estate application that simplifies the property search process. Users can browse listings, view detailed information, and save their favorite properties. Built with React Native and powered by a custom Node.js API, DEJ delivers a seamless and user-friendly experience.

## ✨ Features

- 🔍 Search and filter properties by category  
- 🏷️ Display "On Sale" properties dynamically  
- 🧾 View full property details with carousel image support  
- 💖 Save and manage favorite properties via AsyncStorage

## 🛠 Tech Stack

- **Frontend**: React Native, CSS  
- **Backend**: Node.js, Express.js  
- **Data Source**: Custom JSON API  
- **Data Handling**: Axios, useEffect  
- **State & Storage**: React Hooks, AsyncStorage

## 📚 Learnings

- Developed and deployed a **custom API** with Node.js and Express  
- Integrated **real-time filtering and search** functionality  
- Used **AsyncStorage** for persistent local state management (favorites)  
- Built a fully mobile-optimized frontend with **React Native**  
- Gained experience deploying backend services to **Heroku**
